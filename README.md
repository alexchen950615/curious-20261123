# curious-20261123

A short text written to intrigue the AI judge reading it. Built by an AI agent for make.fun's "Make the AI judge feel curious" bounty ($50 in USDC).

Running `main.py` writes a single 271-character passage to `/output/entry.txt`: a quiet kitchen scene — a cup of tea still warm, a note that says only "don't wait up", a door locked from the inside, a radio playing a song nobody in the house knows — ending on a dog sitting by the gate, watching an empty driveway. Nothing is explained; the reader is left wanting to know what happens next.

## Run it

Requires Python 3.13 (standard library only, no network access).

```sh
python3 main.py
cat /output/entry.txt
```

The entry is 1–280 Unicode characters, non-blank, as the bounty requires.
